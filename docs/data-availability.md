# Data Availability

## What is in This Repository

This GitHub repository contains everything needed to understand and reproduce the
computational workflow: source code, configuration files, force field parameters,
structure files, training data, and pre-computed summary results.

### Included Data

| Directory | Contents | Size |
|-----------|----------|------|
| `data/structures/tobermorite/` | LAMMPS .data files for Tob9, Tob11, Tob11H, Tob14 (CVFF + PCFF) | ~8 MB |
| `data/structures/lj_sets/` | Structure files for specific LJ parameter sets | ~15 MB |
| `data/structures/csh/` | Disordered C-S-H structures from pyCSH | ~3 MB |
| `data/structures/surface_energy/` | Surface slab structures | ~2 MB |
| `data/structures/validation/` | Validation structure files | ~1 MB |
| `data/training/*.csv` | All ML training data (accumulated across AL rounds) | ~2 MB |
| `data/training/models/` | Saved NN weights (NSGA2, NSGA3a, NSGA3b) | ~5 MB |
| `data/reference_results/` | Property tables, error metrics, validation data | ~3 MB |
| `workflows/03_csh_transfer/summary_*.csv` | Extracted density, bulk modulus, deformation data | <1 MB |
| `forcefields/` | CVFF and PCFF interface force field files | <1 MB |

### Not Included (Too Large for GitHub)

The following raw simulation outputs are not included due to size constraints
(total >10 GB). They can be regenerated by running the workflows on an HPC cluster.

- **Raw LAMMPS trajectories** (`.lammpstrj`, `.dump`): MD trajectories for each
  LJ parameter set x polymorph x property calculation
- **Raw LAMMPS log files** (`log.lammps`): Thermo output from which properties
  are extracted
- **Intermediate results.json files**: Per-simulation property extractions
  (summarized in the CSV files above)
- **Full polymer adsorption trajectories**: Production MD runs for all PCE
  configurations and replicas

## Reproducing from Scratch

To regenerate all data from scratch:

1. Follow the HPC setup in `docs/hpc.md`
2. Run Workflow 1 (tobermorite optimization) - produces training data and optimal parameters
3. Run Workflow 2 (charge unification) - produces unified charge sets
4. Run Workflow 3 (C-S-H transfer) - validates on disordered structures
5. Run Workflow 4 (polymer adsorption) - generates adsorption energy data

Each workflow entry-point scripts and configuration files are documented in
`docs/workflow.md`.
