# C–S–H Interface Force Field (IFF) Optimization

A machine-learning-driven active-learning framework for optimizing interface force field
parameters for calcium–silicate–hydrate (C–S–H), the primary binding phase in cement.

The pipeline combines molecular dynamics (LAMMPS), neural-network surrogate models, and
multi-objective optimization (NSGA-II/III) to fit Lennard-Jones parameters against density,
bulk modulus, and surface energy across tobermorite polymorphs (Tob11, Tob11H, Tob14;
Tob9 is included as a reference structure). The resulting parameterization transfers to
disordered C–S–H without re-fitting and is applied to study polymer–C–S–H adsorption
of polycarboxylate ether (PCE) superplasticizers.

## Repository Structure

```
├── workflows/                  Reproducible pipelines (run in order)
│   ├── 01_tobermorite_optimization/   Active-learning LJ optimization
│   ├── 02_charge_unification/         Charge optimization across polymorphs
│   ├── 03_csh_transfer/              Validation on disordered C–S–H
│   └── 04_polymer_adsorption/        PCE adsorption analysis
├── src/
│   ├── mdsetup/               MD simulation setup library (fork of MDSetup)
│   └── pycsh/                 C–S–H structure generator (fork of pyCSH)
├── data/
│   ├── structures/            LAMMPS structure files (.data) for all polymorphs
│   ├── training/              ML training CSVs and saved model weights
│   └── reference_results/     Published property tables, figures, validation data
├── forcefields/               CVFF and PCFF interface force field files (.frc)
├── examples/                  Standalone worked examples for key calculations
├── scripts/                   Utility scripts (data generation, reproducibility)
└── docs/                      Workflow guide, HPC setup, data-availability notes
```

## Quick Start

### Level 1: Inspect Results (no HPC required)

Browse the pre-computed data without running any simulation:

```bash
# Reference property tables
ls data/reference_results/results_summary/

# Training data and Pareto-optimal parameter sets
cat data/training/optimal_parameter_sets_7.csv

# C–S–H transfer validation summaries
head workflows/03_csh_transfer/summary_density.csv
```

The Jupyter notebooks in `workflows/01_tobermorite_optimization/notebooks/` reproduce
the manuscript figures from the CSV data in `data/`.

### Level 2: Representative Runs (HPC cluster with LAMMPS)

Run the NSGA-II active-learning optimization to verify the pipeline:

```bash
# Install dependencies
conda env create -f environment.yml
conda activate csh-iff

# Install the local packages
pip install -e src/mdsetup/

# Run NSGA-II optimization (requires LAMMPS + PBS scheduler)
cd workflows/01_tobermorite_optimization
python main_nsga2.py
```

The script reads training data from `data/training/training_data_145.csv`,
trains NN surrogates, runs NSGA-II optimization, and submits LAMMPS MD jobs
via the PBS scheduler. See `docs/workflow.md` for configuration details.

### Level 3: Full Reproduction (HPC cluster)

The complete optimization sweeps three tobermorite polymorphs (Tob11, Tob11H, Tob14)
across hundreds of LJ parameter sets and requires a PBS/SLURM cluster with LAMMPS.
See `docs/hpc.md` for scheduler templates and environment setup.

## Dependencies

Core requirements (see `environment.yml` for pinned versions):

- Python >= 3.9
- LAMMPS (with PCFF/CVFF force field support, i.e. CLASS2 + KSPACE packages)
- NumPy, Pandas, SciPy, Scikit-learn
- PyTorch (neural network surrogates)
- Pymoo (multi-objective optimization)
- Jinja2, PyYAML, TOML (template engine and config)
- Matplotlib, Seaborn (visualization)
- RDKit (molecular structure handling, via MDSetup)

## Workflows

### 1. Tobermorite Optimization (`workflows/01_tobermorite_optimization/`)

Active-learning loop: sample LJ parameters → run MD on Tob11/11H/14 → extract
density, bulk modulus, surface energy → train NN surrogates → NSGA-II/III Pareto
optimization → select next batch → repeat. Tob9 structures are included for
reference but were not used as optimization targets.

Entry points: `main_nsga2.py`, `main_nsga3a.py`, `main_nsga3b.py`.
Exploratory scripts (BO, CMA-ES, earlier drivers) are in `archive/`.

### 2. Charge Unification (`workflows/02_charge_unification/`)

Optimizes partial charges to be consistent across polymorphs for both CVFF and PCFF
force fields. Includes a PINN-based charge optimization variant (`pinn/`).

### 3. C–S–H Transfer (`workflows/03_csh_transfer/`)

Validates the optimized IFF on disordered C–S–H structures generated by pyCSH across
varying Ca/Si ratios. Pre-computed summaries: `summary_density.csv`,
`summary_bulk_modulus.csv`, `summary_deformation.csv`.

### 4. Polymer Adsorption (`workflows/04_polymer_adsorption/`)

Pre-computed adsorption energies for PCE superplasticizers on C–S–H surfaces at three
chain-to-ester ratios (1:1, 2:1, 3:1). The analysis scripts replot the results from
`data/reference_results/adsorption_energy_*.csv`. Full production trajectories are
not included (>10 GB); see `docs/data-availability.md` for regeneration instructions.

## Examples

The `examples/` directory contains standalone worked examples:
